# Install open62541 for the simulator

The simulator links against open62541 1.5.10 that has the NodeSet loader, the Alarms and Conditions support, and the patch of the branch `1.5` of the repository `open62541-env`. This procedure builds that library from source and installs it into a directory that you choose.

## Prerequisites

- A Debian 13 host with network access, because the build downloads the open62541 source. The build of `open62541-env` on Rocky Linux 8 uses the make target `conf.rocky8`, which this procedure does not cover.
- About 500 MB of free disk space for the source and build directories, and 35 MB for the installation.
- The absolute path of a directory that you can write to for the installation, which this page names `<open62541_install_path>`. A relative path installs into the build directory of `open62541-env`, where the simulator does not look for it.
- The repository root of the simulator as the current directory, because the commands name `../open62541-env` relative to it.

1. Install the packages that the build needs (Debian names):

   <!-- doc-check: skip -->
   ```bash
   sudo apt install build-essential git pkg-config cmake python3 libssl-dev libxml2-dev
   ```

2. Clone the branch `1.5` of `open62541-env` next to the repository. The branch `master` builds open62541 1.3.15, which the simulator does not support:

   <!-- doc-check: skip -->
   ```bash
   git clone -b 1.5 https://github.com/jeonghanlee/open62541-env ../open62541-env
   ```

3. Build and install open62541. The command takes several minutes:

   <!-- doc-check: skip -->
   ```bash
   make open62541 OPEN62541_PATH=<open62541_install_path>
   ```

   The target runs five stages of `open62541-env`. The stage `init` clones the tag `tags/v1.5.10` of open62541 into `../open62541-env/open62541-src`. The stage `patch.apply` applies `patch/1.5.10.p0.patch`, which the server needs. The stage `conf` runs cmake with the NodeSet loader, the full namespace zero, and the Alarms and Conditions support. The stages `build` and `install` compile the library and copy it into `<open62541_install_path>`. When the directory `open62541-src` exists, the target skips `init` and `patch.apply`. When cmake stops with `Could NOT find LibXml2`, install `libxml2-dev` and run the command again.

   When an earlier run left an `open62541-src` that might not hold the patch, remove the source first. The target `distclean` of `open62541-env` removes it, and step 3 then clones and patches the source again:

   <!-- doc-check: skip -->
   ```bash
   make -C ../open62541-env distclean
   ```

4. Optional: to find the stage that fails, run the stages of step 3 one at a time instead of step 3. Clone the source:

   <!-- doc-check: skip -->
   ```bash
   make -C ../open62541-env init
   ```

   Apply the patch:

   <!-- doc-check: skip -->
   ```bash
   make -C ../open62541-env patch.apply
   ```

   Configure the build with the installation path:

   <!-- doc-check: skip -->
   ```bash
   make -C ../open62541-env conf INSTALL_LOCATION=<open62541_install_path>
   ```

   Compile the library:

   <!-- doc-check: skip -->
   ```bash
   make -C ../open62541-env build
   ```

   Install it:

   <!-- doc-check: skip -->
   ```bash
   make -C ../open62541-env install INSTALL_LOCATION=<open62541_install_path>
   ```

   When cmake stops with `Could NOT find LibXml2`, install `libxml2-dev` and run the stage `conf` again.

## Verification

Check that the library exists:

```bash
ls <open62541_install_path>/lib/libopen62541.so
```

```
<open62541_install_path>/lib/libopen62541.so
```

Check that the NodeSet loader header exists:

```bash
ls <open62541_install_path>/include/open62541/plugin/nodesetloader.h
```

```
<open62541_install_path>/include/open62541/plugin/nodesetloader.h
```

Check that the library is built with the Alarms and Conditions support:

```bash
grep UA_ENABLE_SUBSCRIPTIONS_ALARMS_CONDITIONS <open62541_install_path>/include/open62541/config.h
```

```
#define UA_ENABLE_SUBSCRIPTIONS_ALARMS_CONDITIONS
```

The target `make build` in [Build the server and the probe](build.md) runs the last two checks and stops with a message when one fails. [Make targets and variables](../reference/make.md) lists the variables of the target `make open62541`.
