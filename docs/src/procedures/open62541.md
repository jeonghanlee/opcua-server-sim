# Install open62541 for the simulator

Build open62541 1.5.10 with the NodeSet loader and Alarms and Conditions enabled. The simulator uses these features to load its model and serve alarms.

## Prerequisites

- A Linux host with Git, Make, CMake, C and C++ compilers, Python 3, `pkg-config`, and the OpenSSL and libxml2 development libraries.
- Network access to fetch the source, and a writable installation directory.
- A Bash terminal at the simulator checkout root. Keep checkout and installation paths free of spaces.

See the [Quick Start](https://github.com/jeonghanlee/opcua-server-sim/blob/master/docs/QUICKSTART.md) for Debian package names. On Rocky Linux 8, `open62541-env` also provides a platform-specific `conf.rocky8` target.

1. Install the library with the repository script. It clones the `1.5` branch of `open62541-env` into `work/open62541-env-1.5` and installs the library into `work/open62541-1.5.10`.

   <!-- doc-check: skip -->
   ```bash
   bash scripts/install-open62541.bash
   ```

   To use a different installation directory, supply the absolute paths of the installation and an `open62541-env` checkout on branch `1.5`. The target applies the source patch as part of the initial checkout.

   <!-- doc-check: skip -->
   ```bash
   make open62541 OPEN62541_PATH="<open62541_install_path>" OPEN62541_ENV_PATH="<open62541_env_path>"
   ```

## Verification

Use the absolute installation directory for `<open62541_install_path>`. Check that it contains the shared library.

```bash
test -r "<open62541_install_path>/lib/libopen62541.so"
```

Check that the installation includes the features required by the simulator.

```bash
make check-open62541 OPEN62541_PATH="<open62541_install_path>"
```

Both checks exit successfully without output. Continue with [Build the server and the probe](build.md).
